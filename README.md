## 📌 Project Overview

The Expense Tracker allows users to securely manage their financial activities from a single dashboard.

Users can:

- Add and track income
- Record and manage expenses
- View their total balance
- Monitor monthly income and expenses
- Analyze savings
- View recent transactions
- Analyze spending by category
- Manage their profile
- Update their password

The application uses a React frontend connected to a Node.js and Express.js backend through REST APIs. MongoDB is used for storing user and transaction data.

## 🔐 Authentication

The application uses JWT-based authentication to secure user accounts and protected API routes.

Authentication includes:

- User registration
- User login
- Protected routes
- JWT token-based authorization
- Password management

## 📊 Dashboard

The dashboard provides an overview of:

- Total balance
- Monthly income
- Monthly expenses
- Savings
- Recent transactions
- Spending categories
- Financial trends

## 🧾 Transaction Management

Users can manage their financial transactions by adding and viewing:

- Income transactions
- Expense transactions
- Transaction amounts
- Categories
- Dates
- Descriptions
